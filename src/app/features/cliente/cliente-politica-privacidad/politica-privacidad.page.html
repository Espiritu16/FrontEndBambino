Política de Privacidad de Datos Personales

Conoce cómo Bambino Chicken recopila, usa y protege tu información personal.

Ley N.° 29733 - Protección de Datos Personales (Perú) Última modificación: 30 de setiembre de 2025

1. Datos que recopilamos

Podemos solicitar nombres y apellidos, número telefónico, correo electrónico, dirección de entrega e información necesaria para pedidos y delivery. Estos datos son proporcionados voluntariamente por el usuario al usar la página web o nuestros servicios.

2. Finalidad del uso de los datos

Usamos los datos para procesar pedidos, coordinar entregas delivery, brindar atención al cliente, responder consultas o reclamos, mejorar servicios y experiencia del usuario, y enviar promociones o novedades solo con autorización del usuario.

3. Protección de la información

Bambino Chicken aplica medidas de seguridad técnicas y administrativas para evitar acceso no autorizado, pérdida o uso indebido de datos. Las transacciones realizadas en la página web cuentan con medidas de seguridad adecuadas para proteger la información proporcionada.

4. Confidencialidad de los datos

Los datos personales no se venden ni se comparten con terceros, salvo cuando sea necesario para servicios relacionados con delivery, pagos o por requerimientos legales.

5. Derechos del usuario

El usuario puede solicitar acceder a sus datos personales, corregir información incorrecta, solicitar la eliminación de sus datos y revocar autorizaciones otorgadas mediante canales oficiales de atención.

6. Uso de cookies

La página web puede usar cookies para mejorar la experiencia de navegación, recordar preferencias y obtener estadísticas de uso. El usuario puede desactivarlas desde la configuración de su navegador.

7. Modificaciones

Bambino Chicken se reserva el derecho de actualizar esta Política de Privacidad en cualquier momento. Los cambios se publicarán en esta misma página.

8. Contacto

Si tienes consultas sobre esta Política de Privacidad o sobre el tratamiento de tus datos personales, puedes comunicarte con nosotros mediante nuestros canales oficiales de atención.
